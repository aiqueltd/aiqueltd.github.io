FaberAI

Sheet 6 of 7 · Real-time AI coaching

An AI coach that watches how a person moves and gives feedback while they are still moving.

What I did

  • Designed how live video, movement models and language models work together.
  • Built the routing that picks the right prompt for each movement.

How it stays fast

  • Movement models run close to the camera.
  • Answers to similar questions come from a cache.
  • Several agents share the work, so no single step holds up the answer.

Results

  • Under 2 seconds
    From a movement to feedback on it.
  • 3 parts, one system
    A native iPhone app, the backend and a web dashboard.

Built with NestJS · Python · WebRTC · GPT-4 · Redis · Swift
